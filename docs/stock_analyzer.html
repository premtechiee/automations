Stock Analyzer

Indian-equities & mutual-fund analysis pipeline with technicals, fundamentals, sentiment, ranked picks, image & PDF reports, and WhatsApp / Telegram delivery.

Introduction

scripts/stock_analyzer.py is the entry-point for the project's flagship pipeline. It analyses the NIFTY-50 universe (or a custom watchlist), combines three independent signal layers, and emits four ranked buckets — Intraday, Swing, Holding, Sell — alongside a table of mutual funds. A high-resolution PNG report is generated and optionally shipped via WhatsApp or Telegram together with a printable PDF.

Script lives at scripts/stock_analyzer.py. The library code is packaged under src/stock_analyzer/ and is also importable from Python as from src.stock_analyzer import ….

Features

Technical analysis

EMA trend, RSI, MACD, ATR, Bollinger bands, volume, and breakout heuristics — fed into a composite bucket score.

Fundamentals

P/E, P/B, ROE, D/E, sales growth and margins are pulled from the fundamentals fetcher and feed into both ranking and the report panels.

Sentiment

Lightweight headline keyword scorer overlays bullish/bearish bias on every symbol when news data is available.

Four trading buckets

IntradaySwing HoldingSell — each with entry, stop-loss and target levels computed from ATR.

Mutual-fund ranking

NAV, 1y/3y/5y CAGR, expense ratio and risk grade — sortable table embedded in the same image.

Pixel-perfect report

Pillow-rendered PNG with light/dark themes, sector ribbons, heatmaps, indices cubes, plus a paginated PDF for archival.

CLI Reference

Top-level invocation:

python scripts/stock_analyzer.py [global options] [action]

Global options

FlagDefaultDescription
--channel {whatsapp,telegram}whatsappNotification channel for non-dry-run sends.
--theme {light,dark}lightImage theme. Also via STOCK_IMAGE_THEME.
--limit N0Limit universe to first N symbols (testing).
--watchlist PATHdata/stock_watchlist.txtCustom symbol list.
--no-pdfoffSkip PDF generation (image only).

Actions mutually exclusive

FlagBehaviour
--dry-runRun analysis, print to console, do not send.
--nowRun analysis and send through --channel.
--preopen🌅 Pre-open brief (08:00 IST) — US close + today's swing picks.
--morning🔔 Market-open confirmation (09:30 IST) — validate trades after first 15 min.
--afternoon📈 Mid-session update (14:00 IST) — trend + hold/sell guidance.
--testSend a test ping only (verify channel delivery).
--angel ARGS…Forward everything after --angel to angel_one.py.

Session Modes

The three session flags pre-set STOCK_SESSION and a friendly STOCK_SESSION_LABEL environment variable which the report header picks up. They're meant to be wired to a scheduler (Task Scheduler / cron).

FlagSuggested timePurpose
--preopen08:00 ISTUS close + today's swing picks
--morning09:30 ISTValidate trades after market opens
--afternoon14:00 ISTMid-session trend + hold/sell guidance

Examples

# Dry-run on a 10-symbol slice — full console log, no send
python scripts/stock_analyzer.py --dry-run --limit 10

# Send the full report via Telegram with a light theme
python scripts/stock_analyzer.py --now --channel telegram --theme light

# Pre-open scheduled brief
python scripts/stock_analyzer.py --preopen

# Skip the PDF (image + console only) for a fast iteration
python scripts/stock_analyzer.py --dry-run --no-pdf --limit 20

# Use a custom watchlist
python scripts/stock_analyzer.py --watchlist data/my_picks.txt --dry-run

# Delegate to the Angel One sub-CLI
python scripts/stock_analyzer.py --angel paper-trade --once
python scripts/stock_analyzer.py --angel paper-trade --refresh-if-stale
python scripts/stock_analyzer.py --angel paper-report --send --channel telegram

Watchlist

By default the analyser pulls the NIFTY-50 list. Override by pointing --watchlist at a plain-text file with one Yahoo-style symbol per line (e.g. RELIANCE.NS). Lines beginning with # are comments.

# data/my_picks.txt
RELIANCE.NS
TCS.NS
HDFCBANK.NS
# small-caps
DIXON.NS
KEI.NS

Theming

Two themes ship out of the box:

  • light default — clean panels, navy accents, ideal for printing & chat embeds
  • dark — terminal-style with neon accents

Switch via --theme per-run, or set STOCK_IMAGE_THEME=dark in .env for a permanent flip.

Report Anatomy

Every PNG/PDF contains the same panels in this order:

  1. Header banner — date/time + session label
  2. Indian indices cubes — Nifty, Bank Nifty, Nifty IT, etc.
  3. Sector heatmap — % change per sector with auto-fitted labels
  4. Sector ribbon — relative strength bars (right-anchored values)
  5. Bucket panels — Intraday / Swing / Holding / Sell, each with entry / SL / target
  6. Mutual-fund table — top NAV-sorted picks with CAGR and expense ratio
  7. Disclaimer

Every report is also persisted as JSON in data/stock_reports/YYYY-MM-DD_HHMM.json and indexed by data/stock_reports/_index.json for downstream consumers (e.g. the auto-trader and paper-trader).

Delivery Channels

WhatsApp via Green-API

Image is sent first, then the PDF as a document. Failures are logged at WARNING level so they don't go silent.

Telegram native bot

Uses sendPhoto + sendDocument. 120s timeouts so large PDFs don't get cut off.

Heads-up: if you see "failed to send PDF", the most common cause is a stale Green-API instance — open the Green-API console and re-link the WhatsApp account.

Angel One Bridge

All Angel One operations live in scripts/angel_one.py and can be invoked directly or via the --angel passthrough on stock_analyzer.py:

# Either of these works identically:
python scripts/angel_one.py status
python scripts/stock_analyzer.py --angel status

# Compose with stock-analyzer flags
python scripts/stock_analyzer.py --angel paper-report --send --channel telegram

See the dedicated Angel One docs for the full sub-command list (status, portfolio, order, auto-trade, paper-trade, …).

Paper Trading

Paper trading is a sister mode of the auto-trader. It reads the analyser's latest picks, polls real LTPs through Angel One, but never transmits orders — all P&L is virtual. This is the safest way to validate the pipeline before going live.

# 1. Generate today's picks
python scripts/stock_analyzer.py --dry-run

# 2. Run the paper trader (loops every 60s during market hours)
python scripts/stock_analyzer.py --angel paper-trade

# 3. End-of-day report
python scripts/stock_analyzer.py --angel paper-report

State persists across days at data/paper_trader_state.json; full reports archive to data/paper_reports/YYYY-MM-DD_HHMM.txt.

Troubleshooting

Console shows mojibake (₹, box-drawing)Windows cp1252 consoleAlready auto-fixed; reports archived to UTF-8 files. Use Get-Content with -Encoding utf8.
AG8001 Invalid TokenCached Angel session expiredAuto-recovers — first request silently re-auths. Manual: delete data/angel_session.json.
WhatsApp "failed to send PDF"Stale Green-API instanceRe-link account in Green-API console.
Empty bucketsUniverse returned 0 fundamentalsYahoo rate-limit. Re-run with --limit 5 after a minute.
