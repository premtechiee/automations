Gold Price Notifier

Automated gold & silver price intelligence with WhatsApp delivery — self-learning predictions, technical analysis, geopolitical signals, and scheduled briefings.

Python 3.10+ yfinance requests curl_cffi Green API Pillow IST Scheduler

Overview

The Gold Price Notifier fetches live gold and silver prices from multiple sources, runs technical and geopolitical analysis, generates a self-learning price direction prediction, and delivers a richly formatted WhatsApp message (with price-card image) to a configured phone number.

Quick Start

# 1. Install dependencies
pip install -r requirements.txt

# 2. Configure credentials
copy .env.example .env
# Edit .env with your Green API credentials and phone number

# 3. Preview a full update (no WhatsApp send)
python scripts/gold_notifier.py --dry-run

# 4. Send one update immediately
python scripts/gold_notifier.py --now

# 5. Start the automated scheduler
python scripts/gold_notifier.py

scheduler.py src/gold_notifier

IST-aware scheduler running in a 30-second polling loop. Market days are Monday–Saturday. Deferred imports from main.py prevent circular dependencies.

def send_morning_briefing() → None
Trigger a full price update at 08:00 IST on market days (Mon–Sat). Calls send_price_update().
def send_afternoon_check() → None
Conditional afternoon check at 14:00 IST. Sends an update if: (a) significant intraday drop ≥ 0.5%, (b) geopolitical signal changed, or (c) macro regime changed since morning.
def check_price_threshold() → None
Alert if 22K price drops below PRICE_ALERT_THRESHOLD_22K (₹12,500/g). Deduplicates alerts per day using data/gold_alert_state.json.
def run_scheduler() → None
Run the main scheduler loop (30-second poll). Fires morning briefing, afternoon check, and threshold monitor on their configured IST times every market day.

lib/proxy.py

Shared Intel VPN/LAN auto-detection. Imported at module load time — network calls made after importing will automatically use the correct proxy.

ℹ️
At import time, proxy.py probes proxy-dmz.intel.com:912 with a 2-second timeout. If reachable, it sets HTTP_PROXY / HTTPS_PROXY env vars and populates the PROXIES dict. If not reachable (home/cloud), all proxy vars are cleared.
def _is_on_intel_network(timeout: float = 2.0) → bool
Return True if proxy-dmz.intel.com:912 is reachable via TCP within the timeout.
def configure_proxy(https_proxy: str = "") → dict[str, str]
Resolve effective proxy URL (explicit override → Intel auto-detect → none), apply to process env vars, and return a requests-compatible proxies dict.

Module-level export

from lib.proxy import PROXIES   # ready-to-use dict, auto-configured at import
